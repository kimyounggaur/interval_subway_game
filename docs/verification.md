## 자동 검증

332개 시험 통과: 엔진 324개, 저장·판 진행 8개.

- 기획서 부록 A의 297개 위 음을 원문 표에서 읽어 독립 기대값과 비교
- 1~13도 495개 조합의 왕복 식별
- 기준음 21종의 표기 불가능한 조합 30개
- 기본 노선 27역, 확장 포함 45역, 겹임시표 조합 58개
- 환승 13쌍의 대칭성, 이웃 이동 38개, 건반 9개 흰건반과 범위
- 6개 구간·모드의 각 1,000판 생성 제약 및 초기 귀 퀴즈 10,000판
- 미션 배분, 연속 같은 대상 금지, 동일 대상 최대 2회, 기준음과 스탬프 제약
- 정답·오답 안내, 6반음의 두 정답, 재시도, 급행의 스탬프·실패 기록 불변
- 저장 복구, 중복 스탬프 방지, 최대 2개 복습, 최근 20판, 버전·손상 복구

타입 검사, 형식 검사, Next.js 정적 빌드도 검증합니다.

18개 시나리오를 각 2,000회 실행하는 `npm run sim`은 자체 구현의 진단입니다. 원본 참조 엔진·검증 자료와 비교한 결과가 아닙니다. 문서의 평균 판 수와 차이가 있을 수 있습니다.

## 실제 브라우저 검증

360×640 및 390×844 iframe으로 실제 모바일 너비를 만들어 확인했고, 넓은 화면에서는 최대 480px 기둥으로 표시했습니다. 360px 프레임의 실제 콘텐츠 너비는 세로 스크롤바를 제외해 345px이며 가로 스크롤이 없고 버튼은 44×44px 이상이었습니다. 하단 주 동작은 프레임 높이 640px 아래에 고정됐습니다.

- 처음 안내 3단계: 세기 → 반음 이동 → 노선·역 선택·도착
- ① 노선 찾기: 6문제 한 판, 스탬프 완주와 급행 해금
- ② 가운데 역: 읽기·한 칸 이동·역 만들기, 의도적인 첫 오답과 최대 2문제 복습, 총 7문제 완주
- ③ 기준음 바꾸기: 6문제 완주
- ④ 끝 역: 6문제 완주, 가려진 역 만들기
- ⑤ 귀: 초기 보기 5개, 듣기 실행, 2회 오답 뒤 공개, 6문제+2복습 완주
- ⑤ 환승: 6문제 완주
- 급행: 20초 판 및 10초 판 완주, 의도적 오답·시간 초과 처리, 최고 기록, 스탬프 8/8 보존
- 새로고침 뒤 피드백 단계부터 이어하기, 중복 스탬프 없음
- 자유 운행: C 단3도→증2도 환승, B 증5도 F 겹올림, E♭ 증1도 제자리표
- 문제 수·전체 구간 개방·급행 시간 설정의 저장

귀 문제의 소리 구별은 자동으로 판단하지 않았습니다. 브라우저 재생 호출과 진행만 확인했습니다. 기기의 스피커 출력, 아이폰 무음 스위치, 실제 학생의 학습 효과, 화면 읽기 프로그램의 실제 낭독은 실기기 확인이 남습니다.

## 원본 누락에 따른 제한

프롬프트는 기획서 v1.1 및 부록 F·G를 요구하지만 제공 기획서는 v1.0, 부록 E까지입니다. Google Drive 관련 파일명과 같은 폴더를 검색했으나 `interval.reference.ts`, `interval_golden_v1.json`, `interval_golden_test.ts`는 찾지 못했습니다. 자체 시험을 이 원본 시험으로 바꿔 부르지 않습니다. 규칙은 제공된 기획서를 기준으로 재구현했습니다.

위 브라우저 검증은 Sites 원본 개발 당시의 기록입니다. GitHub 이관 과정에서는 브라우저·실제 청취 검증을 새로 수행하지 않았습니다. Vercel에서 빌드할 정적 내보내기 구성은 포함되어 있으며, Vercel 연결·배포는 이번 이관 범위에 포함되지 않습니다.
